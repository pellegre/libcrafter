# MQTT Codepoint Authority Table

Compact, code-facing authority for the `crafter` MQTT layer. This table is the
source of truth for MQTT constants: `constants.rs`, oracle specs, tests,
fixtures, and examples must match it.

Every value here is derived from and must match
[`mqtt-manifest.md`](mqtt-manifest.md). The manifest carries the full OASIS/IANA
evidence. On any disagreement, this table is corrected to the manifest, never
the reverse.

Row format: `NAME = value  # source`.

## Ports

```
MQTT_PORT = 1883  # IANA service registry: mqtt/tcp
MQTT_SECURE_PORT = 8883  # IANA service registry: secure-mqtt/tcp; TLS/opaque, not cleartext decode
```

## MQTT 5.0 AUTH

Source: OASIS MQTT 5.0 sec. 3.15.

```
MQTT_AUTH_VARIABLE_HEADER_MIN_LEN = 0  # reason code/property length may be omitted for Success with no properties
MQTT_AUTH_REASON_SUCCESS = 0x00
MQTT_AUTH_REASON_CONTINUE_AUTHENTICATION = 0x18
MQTT_AUTH_REASON_RE_AUTHENTICATE = 0x19
```

AUTH variable header order is Authenticate Reason Code, then Properties. Allowed
AUTH properties are Authentication Method (`0x15`), Authentication Data
(`0x16`), Reason String (`0x1F`), and User Property (`0x26`). AUTH has no
payload.
